# 面積工坊 ✂️

剪一刀、拼一拼，公式自己來！國小五年級「面積」單元的平板互動練習，依課本例題設計操作活動，每站標示對應的單元教學目標。

| 節次 | 工作台 | 操作內容 | 教學目標 |
|---|---|---|---|
| 8-1 | 剪一刀變長方形 | 長方形斜剪拼成平行四邊形／梯形、自選位置沿高剪開拼長方形 | 1-1 |
| 8-1 | 平行四邊形的底和高 | 指出底和高、選出高、拉線畫高、公式練習 | 1-2、1-3 |
| 8-2 | 三角形複製機 | 兩個全等三角形拼成平行四邊形／長方形，找出不同拼法 | 2-1、2-3 |
| 8-2 | 三角形的高 | 選出高、拉線畫高（銳角、鈍角、直角、斜的底） | 2-2、2-3 |
| 8-3 | 梯形複製機 | 兩個全等梯形拼成平行四邊形、找梯形的高、用三角板量高、指出上底下底和高 | 3-1、3-2、3-3 |
| 8-4 | 等底等高實驗室 | 滑動頂點／上邊、扣條推斜、底或高變成幾倍 | 1-4、2-4、2-5 |
| 8-4 | 釘板實驗室 | 拉橡皮筋圍出指定面積的三角形、平行四邊形、梯形 | 1-4、2-4、2-5 |
| 8-4 | 複合圖形工地 | 多種切法、補上扣除、道路平移、素養評量 | 4-1、4-2 |
| 練習 | 練習園地（八） | 公式應用與易錯題 | 1-3、2-3、3-3、4-1、4-2 |
| 複習 | 面積大考驗 | 10 題計時總複習 | — |
